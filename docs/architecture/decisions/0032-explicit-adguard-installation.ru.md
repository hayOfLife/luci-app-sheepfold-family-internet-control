# ADR-0032: Отдельная подтверждённая установка AdGuard Home

- Статус: Принято
- Дата: 2026-10-25
- Теги: `§aghinst`, `§aghplan`, `§dompol`
- Связанные документы: [Установка AGH](../../adguard-home-installation.ru.md), [ADR-0007](0007-site-filtering-backends.ru.md)

## Контекст

Владелец запросил установку AGH из «Интеграции» по профилю NanoPi, но без перезаписи
настроенного AGH и без переноса тяжёлых параметров на маломощный роутер. Старое согласие
на управление URL-фильтром не разрешает менять DNS и учётные записи.

## Рассмотренные варианты

1. Расширить `adguard_auto_manage`: отклонено из-за незаметного расширения полномочий.
2. Редактировать любой существующий YAML: отклонено из-за чужих настроек и различий схем.
3. Отдельная fresh-only операция с предварительными проверками и снимками: принято.
4. Уникальный случайный пароль: рекомендован для безопасности, но владелец явно выбрал
   общий начальный `admin` / `password` с пониманием риска домашней сети.
5. Генерация bcrypt на роутере через библиотеку или временный мастер: не нужна для
   публичного фиксированного пароля; проверенный готовый хеш уменьшает код и зависимости.

## Решение

Новая кнопка имеет собственное подтверждение. Установщик использует системный пакетный
менеджер через общий adapter, создаёт только новую конфигурацию проверенной схемы,
сохраняет snapshots и пытается вернуть прежний DNS при проверяемой ошибке. Существующие
данные, IPv6, Podkop/firewall не переписываются автоматически. Панель слушает выбранный
LAN IP, не wildcard. Начальный пароль показывается с предупреждением до согласия.

ADR-0007 и права обычного URL-filter adapter не заменяются. Его узкое HTTP-исключение
действует только для собственного текущего локального адреса с квитанцией установки.

## Последствия

- В runtime не добавляются Python, bcrypt, YAML-редактор или новая служба-оркестратор.
- Поддержка ограничена версией/топологией/ресурсами, названными в профильном документе.
- Общий пароль остаётся известным риском; владелец может сменить его после установки.
- При обрыве питания возможен ручной возврат DNS; crash-safe обещания нет.

## Проверка

`adguardInstall.test.mjs`, `adguardInstallUi.test.mjs`, `adguardIntegration.test.mjs`,
`testIpkPermissions.test.mjs` и ручной `adguardNativeProbe.mjs` проверяют разные границы.
Локальные тесты не заменяют OpenWrt LAN/Podkop/reboot и измерение пика RAM.

## Когда пересматривать

При новой схеме AGH, доказанной поддержке IPv6/нескольких DNS-инстансов, измерениях на
минимальном роутере или изменении решения владельца о начальных данных входа.
